# HWHArchdemonExt

An add-on for HeroWarsHelper for the Archdemon event in Hero Wars. It runs the free Abyss
chapter, collects the team you set and stops right before the Archdemon — you attack yourself.
If a run does not work out, it resets the chapter and tries again.

## Install

1. Install HeroWarsHelper in Tampermonkey.
2. Install [HWHArchdemonExt.user.js](dist/HWHArchdemonExt.user.js) after it.
3. Open the helper menu: **Others → Adventure (Arch)**.
